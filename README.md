# raspisator

Солвер для задач целочисленного линейного программирования.

**Все классы МАКСИМИЗИРУЮТ целевую функцию.**

## Code Style

Стиль кода описан в `.cland-tidy` и `.clang-format`. Однако есть набор дополнительных правил, которые поддерживаются в
проекте.

### Exceptions

- Каждое сообщение должно быть грамматически полным и корректным предложением. В конце всегда надо ставить точку.
- Для обозначения имён в сообщении об ошибки используются одинарные кавычки. Пример: `Variable 'test' doesn't exist.`

## Random Generators

Генераторы случайных чисел надо принимать по ссылке. Пример:

```c++
template <typename Gen>
  requires std::uniform_random_bit_generator<Gen>
size_t random_number(Gen& random);
```
