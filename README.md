# raspisator

Солвер для задач целочисленного линейного программирования.

## Code Style

Стиль кода описан в `.cland-tidy` и `.clang-format`. Однако есть набор дополнительных правил, которые поддерживаются в проекте.

### Exceptions

- Каждое сообщение должно быть грамматически полным и корректным предложением. В конце всегда надо ставить точку.
- Для обозначения имён в сообщении об ошибки используются одинарные кавычки. Пример: `Variable 'test' doesn't exist.`

### Tests

- Имена тестов должны быть в CamelCase и не должны включать в себя Test
